## 분석

### 대역폭

[https://blog.naver.com/vtmbloodline/221504780925](https://blog.naver.com/vtmbloodline/221504780925)

- DDR5 102.4GB/s(quad-channel)
- Memery Speed * Memory bus = Bandwidth
- 14Gbps * 384bit(32bit*12EA) =  14Gbps*384bit/8bit = 672GB/s
### GDDR7

- 32Gbps * 32bit = 128GB/s per chip
- 128*16EA = 2048GB/s = 2TB/s (엔비디아 RTX 5090) 32G 용량
### HBM3E

- 9.6 * 1024/8/1024 = 1.2TB/s
- 1.2TB/s * 16EA = 16TB/s (엔비디아 GB200 NVL2) 384GB 용량
### M1 Max

- 128-bit 4 채널(512-bit) LPDDR5 3,200 MHz 통합 메모리
### M2 Ultra

- M2 Ultra = M1 Max * 2
- 128-bit 8 채널(1,024-bit) LPDDR5 3,200 MHz 통합 메모리
- 전송 속도: 6,400 MT/s, 대역폭: 819.2 GB/s
- 최대 192GB 용량. VRAM의 경우 128GB 통합 메모리 구성 기준 최대 96GB까지 할당한다.
- 16TB/384GB = 42.666   819.2/192 = 4.266
- 대역폭은 20배차이지만 용량대비 대역폭은 10배차이
### M4 Max

- 64-Bit 8 채널(512-Bit) LPDDR5X 4,266 MHz 통합 메모리
- M3 Ultra는 M4 Max 2개 붙이니까 대역폭은 M2 Ultra 이상일듯
### META 인공지능 가속기 MTIAv1

- 연산 칩을 RISC-V 기반으로 커스텀 설계하여 64개의 각 그리드별로 다른 연산을 동시에 수행할 수 있다. 또한 SRAM을 캐시처럼 활용하는 방식을 택했고, 오프칩은 LPDDR5 DRAM
